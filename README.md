# Ivey

A playful, single-page personal greeting with a timed introduction, animated GIFs, images, and sound effects.

The page sequences an introductory prank, animated reveals, and background music.

## Preview

Open [index.html](index.html) in a browser, or serve this directory with a local static server. No package installation, build step, backend, or environment variables are required.

Bootstrap is loaded from a CDN, so the full styling requires internet access. Browsers may delay audio until the first click or tap.

## Customize

HTML, CSS, and JavaScript live in index.html. Images, GIFs, and audio files are stored alongside it. Update the text and asset references there, preserving filename spelling and letter case for static hosts.

## Deployment and checks

Publish this folder through GitHub Pages or another static host, keeping index.html at the site root and including all referenced media files. Preview the introduction, images, animations, and audio controls in a browser before publishing. There is no automated test suite.
